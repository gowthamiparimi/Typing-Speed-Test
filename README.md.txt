# Typing Speed Test Using Python

## Project Description

The Typing Speed Test is a Python-based GUI application that measures the typing speed and accuracy of users.

The application displays a random sentence to the user. After typing the sentence, the system calculates the Words Per Minute (WPM) and typing accuracy.

## Features

- Random sentence generation
- Typing speed calculation
- Accuracy measurement
- User-friendly graphical interface
- Restart option

## Technologies Used

- Python 3
- Tkinter
- Time Module
- Random Module

## How to Run

1. Install Python.
2. Open project in Thonny.
3. Run main.py.
4. Click Start Test.
5. Type the displayed sentence.
6. Press Enter.
7. View typing speed and accuracy.
